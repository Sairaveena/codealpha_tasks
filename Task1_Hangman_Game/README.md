# Task 1 - Hangman Game

## Project Overview

A Hangman word-guessing game developed using Python and Tkinter. The player guesses letters to find the hidden word before running out of lives.

## Objective

To develop an interactive Hangman game with a graphical user interface.

## Technologies Used

- Python
- Tkinter
- Random Module

## Features

- Random word selection
- Letter guessing
- Hidden word display
- Guessed letters tracking
- Lives remaining display
- Win and game-over messages
- Graphical user interface

## Project Structure

```text
Task1_Hangman_Game/
├── main.py
├── words.txt
└── README.md
```

## How to Run

Open the project folder in VS Code or Command Prompt.

Run:

```bash
python main.py
```

The Hangman game window will open.

## Requirements

Python is required. Tkinter is used for the graphical interface.
