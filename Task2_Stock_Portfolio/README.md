# Task 2 - Stock Portfolio Tracker

## Project Overview

A simple stock portfolio tracker developed using Python. The application allows users to manage stocks, track quantities and prices, and calculate the total portfolio value.

## Objective

To develop a simple application for managing and tracking a stock portfolio.

## Technologies Used

- Python
- Tkinter
- SQLite

## Features

- Add stock details
- Track stock quantity
- Store stock information
- Calculate portfolio value
- View portfolio records
- Graphical user interface
